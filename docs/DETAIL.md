# 详情：小红书图片保存

## 功能

一个工具 `xhs_save_images`：给定小红书**用户主页链接**和**本地目录**，把该用户全部笔记的图片批量保存下来。

- 自动翻页采集全部笔记（走页面自身的分页接口，不猜接口签名）
- 逐篇提取发布日期与图片地址
- 下载原图，失败自动退回网页压缩版
- 文件名 `日期_标题_序号.扩展名`，全部平铺在一个文件夹
- 生成 `_清单.csv`（文件名、日期、标题、笔记 ID、大小、画质）
- 断点续传：详情有缓存、已下载的文件直接跳过

## 用法

会话里直接说「把 \<主页链接\> 的图片保存到 \<目录\>」，或让 agent 调用工具：

- `userUrl`：用户主页链接（`https://www.xiaohongshu.com/user/profile/...`）
- `outputDir`：保存目录（绝对路径，自动创建）
- `quality`：`original` 原图（默认）/ `web` 压缩版
- `limit`：只处理前 N 篇（调试用）

## 登录

小红书未登录时不暴露笔记列表，所以：

1. 首次调用会弹出一个**专用 Chrome 窗口**（独立登录档案，不影响你日常浏览器）；
2. 用手机小红书或微信扫码登录（勾选记住我）；
3. 登录态保存在 `~/.dsh/xhs-saver/profile`，之后免登；
4. 登录过期时工具返回 `login_required` 并给出提示，重新登录后重试即可，进度不丢。

## 限制

- 只保存图片，视频笔记仅取封面图。
- 必须已安装 Chrome 或 Edge（可用 `XHS_CHROME` 指定路径）。
- 大账号需要几分钟，工具硬超时 20 分钟。
- 请遵守平台条款与版权，仅限个人使用。
